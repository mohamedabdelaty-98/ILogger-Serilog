# Serilog and Logging in .NET

A practical technical guide for configuring Serilog, writing structured events, choosing sinks, and operating SQL Server logging in ASP.NET Core.

## Start here

[Read the Serilog and Logging Technical Guide](serilog-logging-guide)

## Topics covered

- Logging fundamentals and the Serilog event pipeline
- Logger configuration, minimum levels, and sink filtering
- Message templates and structured properties
- Enrichers, request context, and distributed trace identifiers
- Console, file, and SQL Server sinks
- An ASP.NET Core implementation example
- Team standards, troubleshooting, and a knowledge check

> The guide uses general ASP.NET Core examples. Confirm package compatibility and SQL schema against your application’s target framework and installed Serilog versions.
